Online Update

Hier kann das SmartAndRelax WLAN-Modul direkt über das Internet aktualisiert werden.

Wichtig: Während des Updates das Modul und die Pumpe nicht vom Strom trennen.

Update durchführen

Empfohlene Reihenfolge:

1. zuerst Weboberfläche / LittleFS aktualisieren

2. nach dem Neustart diese Seite erneut öffnen

3. danach Firmware aktualisieren

Hinweis

Nach erfolgreichem Update startet das Modul automatisch neu. Die Verbindung zur Seite kann dabei abbrechen.

Die Update-Dateien werden von GitHub / jsDelivr geladen.
