# SmartAndRelax 2.0.0

**Original release date:** 2024-07-04  
**Internal firmware identifier:** `2024-07-04-001`

This release provides the historical source code corresponding to SmartAndRelax 2.0.0.

The historical source files are preserved in their original state. This release documentation was added retrospectively in August 2026 to provide a transparent and traceable archive of the SmartAndRelax release history.

## Origin

SmartAndRelax is based on the open-source project:

**WiFi remote for Bestway Lay-Z-SPA**  
by visualapproach and contributors.

Original project:  
https://github.com/visualapproach/WiFi-remote-for-Bestway-Lay-Z-SPA

SmartAndRelax contains modifications and extensions to the original project, including German localization and SmartAndRelax-specific adaptations.
