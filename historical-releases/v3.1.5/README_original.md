# SmartAndRelax

A fork of visualapproach's whirlpool software - Translation into German

Der Code von SmartAndRelax basiert auf der Software von visualapproach und wird unter den Bedingungen der GNU General Public License v3.0 weiterentwickelt. Auch die Hardware basiert zum größten Teil auf der Arbeit von visualapproach.

Originalprojekt von visualapproach:
https://github.com/visualapproach/WiFi-remote-for-Bestway-Lay-Z-SPA

## Änderungen und Quellenhinweise

SmartAndRelax enthält Änderungen und Erweiterungen von Michael Krenner / MK-Innovations.
Diese Version ist Firmware 3.1.5, veröffentlicht am 20.07.2026.

Bei der Entwicklung der Smart-Schedule-Funktion wurden Teile der Implementierungsstruktur des unter GPL-3.0 veröffentlichten WifiWhirl-Projekts als Grundlage verwendet und für SmartAndRelax angepasst und weiterentwickelt.

WifiWhirl:
https://github.com/WifiWhirl/WifiWhirl-Software

Alle GPL-basierten Bestandteile und die daran vorgenommenen Änderungen werden unter den Bedingungen der GNU General Public License v3.0 bereitgestellt. Der vollständige Lizenztext befindet sich in der Datei `LICENSE`.
