# SmartAndRelax 3.1.5 – Release Notes

**Version:** 3.1.5  
**Release date:** 2026-07-20

## Changes

### Smart Schedule

✅ **New:** Smart Schedule – intelligent scheduling for automatic
heating of the whirlpool.

Smart Schedule allows a target temperature and target time to be
specified. SmartAndRelax calculates and manages the required heating
process automatically so that the desired temperature can be reached
at the planned time.

### Pump and display communication

- Improved communication stability with supported Lay-Z-Spa
  pump and display configurations
- Improved stability for JST-XH based pump variants
- Additional improvements to display and command handling

### Stability

- Additional system stability improvements
- General bug fixes
