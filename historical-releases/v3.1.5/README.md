# SmartAndRelax 3.1.5

Historical source archive for SmartAndRelax firmware version 3.1.5.

**Original release date:** 2026-07-20

**Internal firmware identifier:** `3.1.5`

The source code contained in this directory represents the archived
source state corresponding to SmartAndRelax firmware version 3.1.5.

The historical source files are preserved in their original state.

SmartAndRelax is based on the GPL-3.0 licensed
WiFi remote for Bestway Lay-Z-SPA project by visualapproach and contributors.

Original project:

https://github.com/visualapproach/WiFi-remote-for-Bestway-Lay-Z-SPA

See the repository root for complete license, attribution and
release-history information.

## Smart Schedule

SmartAndRelax 3.1.5 includes the Smart Schedule functionality.

Parts of the Smart Schedule implementation in this historical release
are based on and adapted from the GPL-3.0 licensed WifiWhirl project.

WifiWhirl:

https://github.com/WifiWhirl/WifiWhirl-Software

Further attribution and modification information is provided in the
corresponding source files and release notes.

## Historical archive notice

SmartAndRelax firmware version 3.1.5 was originally released on
2026-07-20.

This historical source archive was added to the public GitHub
