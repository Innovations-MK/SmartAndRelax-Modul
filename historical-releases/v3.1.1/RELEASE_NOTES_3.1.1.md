# SmartAndRelax 3.1.1 – Release Notes

**Version:** 3.1.1

## Changes

### Cloud connectivity

SmartAndRelax is now cloud-enabled and supports remote access through the SmartAndRelax WebApp:

https://webapp.mk-innovations.de

This allows supported systems to be controlled remotely without requiring a VPN or additional network configuration.

The WebApp also provides functionality for storing, analyzing and evaluating water-quality data over time.

### Improved Wi-Fi connectivity

The Wi-Fi connection handling was optimized to provide more stable connections, including when using older Wi-Fi repeaters.

### Improved browser compatibility

Browser compatibility was improved, particularly for Safari.

If loading or connection problems occur, polling can be enabled in the web configuration. This provides more reliable and continuous data transmission in affected browser environments.

### MQTT and Cloud stability

Additional stability improvements were made to MQTT and Cloud communication.

### Filter pump behavior

Fixed an issue that could cause sporadic activation of the filter pump.
